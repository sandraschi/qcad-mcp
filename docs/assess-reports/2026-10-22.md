## Deductions detail (file:line evidence)

### HIGH (-8 each)

1. **Pyright gate red, CI non-blocking** — `uv run pyright src/` reports 100 errors
   (PrefabApp `.add`/kwarg drift in `src/qcad_mcp/tools/prefab_cards.py:32-104`,
   `httpx.QueryParam` in `src/qcad_mcp/tools/script_tools.py:138`, etc.).
   `.github/workflows/ci.yml` runs pyright with `continue-on-error: true` ("101
   pre-existing third-party-stub errors — needs a dedicated typing pass").
   Gate failure with an acknowledged plan is still a failing gate. DEFERRED this run:
   needs a dedicated typing sprint (pin/fix prefab_ui + ezdxf stubs), not a drive-by.
2. **Webapp missing catch-them-all pages** — `webapp/src/pages/` has 18 domain pages
   (Dashboard, Demo, Depot, Viewer, Extrude, Analyse, Layers, Blocks, Scripts, Agentic,
   Batch, Pipeline, Playground, Models, Logs, Settings, Help, apps) but no dedicated
   Chat, Skills, Tools, or Inbox pages (`WEBAPP_SOTA_STANDARDS.md` §III). Chat exists
   only as `FloatingChat.tsx` component. DEFERRED: 4-page build, propose as follow-up.

### MEDIUM (-4 each)

3. **No bun.lock (npm instead of bun)** — `webapp/package.json` present, no
   `webapp/bun.lock`; `just bootstrap` + CI use `npm ci` (works: `webapp/package-lock.json`
   exists). Fleet standard is bun (`BUN_STANDARDS.md`). DEFERRED: npm→bun migration
   touches CI + docs; functional today.
4. **just bootstrap skips pre-commit install** — `justfile:17-18` runs
   `uv sync --all-extras` + `npm install` but never `pre-commit install`, so the
   `.pre-commit-config.yaml` + materialised hook (present) are bypassed on fresh clones.
   FIX in this run.
5. **Missing Fleet Starts launcher** — `mcp-central-docs/starts/qcad-mcp-start.bat`
   absent (`Test-Path` False), so the repo is invisible in the Fleet Starts search UI
   (`:10791`). FIX in this run (file lives in mcp-central-docs, committed there).
6. **plugin.json shape** — `.claude-plugin/plugin.json` inlines hooks instead of
   referencing `hooks/hooks.json` (which exists with a valid SessionStart text hook).
   Standard: `"hooks": "../hooks/hooks.json"`. FIX in this run.
7. **No portmanteau (42 discrete tools)** — `src/qcad_mcp/tools/*.py` registers 42
   individual `@mcp.tool` ops via `register_all`; no single `Literal`-discriminator
   entry. DEFERRED: modular per-domain registration is deliberate and Desktop-friendly;
   consolidation would churn all client configs for no behaviour gain. (Flagged OPEN per
   checklist §1B; revisit only if the standard mandates it for >15-tool servers.)
8. **LLM state page-local, not Zustand** — `webapp/src/store/` holds only
   `connection.ts`; provider/model selection lives in `SettingsPage.tsx`/`FloatingChat.tsx`
   `useState` with `localStorage` keys. Standard wants global LLM store (§VI). DEFERRED:
   works correctly; migration is a refactor, not a fix.
9. **Font/contrast debt (P4)** — ~100 hits of `text-xs` on UI text (buttons, labels,
   table headers, e.g. `AgenticPage.tsx:132`, `LayersPage.tsx:103`,
   `Dashboard.tsx:117-134`) and `text-slate-400/500` body text on dark backgrounds
   (e.g. `AnalysePage.tsx:79`, `HelpPage.tsx:49`). Allowed only inside `<pre>`.
   DEFERRED: design-system sweep across 18 pages; counted once as representative.
10. **.mcpbignore missing webapp/** — `mcpb/.mcpbignore` excludes `.venv/`,
    `node_modules/`, `native/`, `tests/`, `data/`, `*.bak*` but not `webapp/`
    (nor `web_sota/`). Risk: webapp bundles into the Desktop bundle. FIX in this run.
11. **No streaming chat proxy** — `POST /api/llm/chat` proxy exists
    (`src/qcad_mcp/server.py`, backend-only key handling ✓) but no
    `/api/llm/chat/stream` (SSE). The only `StreamingResponse`
    (`server.py:909`) serves logs. DEFERRED with the Chat-page build (HIGH #2).
